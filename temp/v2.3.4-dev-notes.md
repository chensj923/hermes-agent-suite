## Hermes Buddy v2.3.4-dev

### 修复与改进
- **服务端准备脚本现在会尝试启动 LLM**：此前脚本只重启 Gateway，导致 LLM `:8800` 经常未监听。现在会先检查并尝试启动 `hermes api_server run --host 0.0.0.0`，失败时给出明确手动命令。
- **连接诊断区分"协议错误"与"地址格式错误"**：原来任何 URL 解析失败都显示"协议错误"，容易误导。现在会提示"地址无法被解析"并清理首尾不可见字符。
- **更新横幅关闭按钮增强**：`×` 现在同时响应 click 与 pointerdown，并阻止冒泡，解决点击无法关闭的问题。
- **配置检查更完整**：`config.yaml` 扫描增加 `api_server_host` / `llm_host` / `model_router_host`，提醒改成 `0.0.0.0`。

### 使用提示
如果服务端 LLM 端口仍未监听，请重新在连接页点「生成服务端准备脚本」，复制到 Hermes 主机执行。脚本会打印 `LLM 地址` 与 `API Key`。
