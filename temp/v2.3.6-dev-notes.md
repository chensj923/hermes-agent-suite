## 关键修复：LLM 端点根本不在 8800，而在 22122（与 Gateway 同端口）

这是本次最核心的修正。之前几个版本一直在错误的方向上排查。

### 根因

Buddy 整个代码库都基于一个**过时且错误的假设**：

> 「LLM 推理端点在 `:8800` 独立进程，Gateway 在 `:22122` 独立进程」

但服务端真正的部署脚本 `scripts/setup-server.py` 生成的实际配置是：

```yaml
platforms:
  api_server:
    enabled: true
    extra:
      host: 0.0.0.0
      port: 22122      # ← 与 Gateway 同一个端口！
```

同时 `.env` 里写入 `API_SERVER_PORT=22122`。

**结论**：`/v1/chat/completions`（LLM 推理）是 Gateway 的一个 `api_server` 平台，**和 Gateway 共用 22122 端口，不是独立进程**。

所以：
- 诊断报「8800 未监听」是**误报**——那个端口本来就不该有进程；
- 前几版 bootstrap 脚本去「启动 8800 的 LLM」是**方向性错误**；
- `hermes` CLI 也确实没有 `api_server` / `llm` / `router` / `server` 这些子命令（`serve` 是 dashboard，`model` 不接受 `--host`），所以必然失败。

你这次回传的 `hermes --help` 全量子命令清单把这件事彻底坐实了 —— 候选子命令全部 `invalid choice` / `unrecognized arguments`。

## 改了什么

### 1. LLM 端口模型统一为「与 Gateway 同端口 22122」

- `src/agent/brain.js`：`deriveLlmEndpoint()` 不再把 Gateway 端口强行换成 8800，改为**沿用 Gateway 同端口** + `/v1/chat/completions`。删除已失效的 `LLM_PORT_CANDIDATES`。
- `src/renderer/app.js`：三处 `8800` 默认值 → `22122`（主机推导、连接回显、生成脚本端口）。
- `src/renderer/index.html`：LLM 输入框 placeholder 与提示文案改为 `:22122`，并说明「与 Gateway 共用端口」。
- `src/connection-store.js`：推导关系注释同步订正。

### 2. 服务端准备脚本不再去启动不存在的 8800 进程

`src/server-bootstrap.js` 第 4 步整体重写：

- 从服务端 `.env` 的 `API_SERVER_PORT` / `config.yaml` 的 `platforms.api_server.extra.port` **读取真实 LLM 端口**（默认 22122）；
- 确认 `api_server` 平台是否启用，**未启用则自动写入配置**并提示第 5 步重启后生效；
- 确认该端口在监听（由 Gateway api_server 平台提供）；
- **删除**了原先「尝试 `hermes api_server/llm/serve/router/model/server`」的瞎猜逻辑；
- 脚本末尾打印的 LLM 地址改用真实读到的端口；
- 生成的脚本里已完全不出现 `8800`。

### 3. 文档订正

`docs/WINDOWS_CLIENT.md`：端口约定、连接表单示例、排查步骤中的 `:8800` 全部改为 `:22122`，并明确写出「LLM 是 Gateway 的 api_server 平台，与 Gateway 共用端口，`hermes` 没有 api_server 子命令」。

### 4. 测试补齐（76/76 通过）

- 修正了 `agent.test.js` / `connection-store.test.js` / `session-manager.test.js` 里断言旧 `8800` 推导的用例；
- 修正 `server-bootstrap.test.js` 中断言 `8800` / 「预期 LLM 端口」的用例；
- **顺带修掉了两个此前一直没被发现的遗留失败**：
  - v2.3.3-dev 改 glob 语义后 `tools.test.js` 的 `*.md` 用例未同步（新语义：无斜杠短模式匹配任意深度，便于整树扫描）；
  - v2.3.1-dev 把 managementUrl 改成「不再自动推导」后，`connection-store.test.js` 里 4 个仍断言推导成 `:8700` 的用例未同步。
  - 全量测试从 35/39 提升到 **76/76 全绿**。
