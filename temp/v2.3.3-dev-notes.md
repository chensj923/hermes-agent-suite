# Hermes Buddy v2.3.3-dev

## 修复：大型工作目录上的命令/扫描超时问题

用户反馈多个 `Get-ChildItem -Recurse` 整盘递归扫描命令在 30s 超时被强制中断、被标记为「失败」。根因：工作目录是一个很大的网络同步盘（SynologyDrive），PowerShell 的 `Get-ChildItem -Recurse -Include` 递归整盘极慢，极易超时。

### 改动
- **`find_files` 支持多模式 + 根目录匹配**
  - 一次可传多个逗号分隔的 glob：`*.pem,*.key,*.p12,*.pfx` 或 `*pass*,*secret*,*key*`。
  - 修复无斜杠短模式（如 `*.pem`、`*pass*`）无法命中工作区根目录文件的问题（原来必须带 `**/`）。
  - 新增可选 `maxDepth` 参数，可浅扫大目录（如 `maxDepth: 4`）。
  - 该工具自带文件数上限（2000）并自动跳过 `node_modules`/`.git`/`dist` 等目录，在大型或网络同步盘上远快于手写递归，且不会超时。
- **引导 agent 优先用有界工具**
  - 工具描述与系统提示明确：按名称/扩展名找文件用 `find_files`；长命令应提高 `timeout_seconds`（最大 600）。
  - 上述三条失败的扫描用 `find_files` 可在瞬间完成。
- **`run_command` 实时流式输出**
  - 命令执行过程中把 stdout/stderr 实时回传到右侧「执行记录」卡片，长命令边跑边显示进度，不必等结束。
  - 超时不再静默「失败」：明确标注「命令超时（已返回部分结果，命令未完成）」，并把已产出的输出一并交回，模型可据此换更快的方式。
- **`search_content` 的 `filePattern` 同样修正根目录匹配。**

### 受影响文件
