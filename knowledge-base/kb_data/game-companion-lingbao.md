# 游戏陪伴模式设计草案（对标王者荣耀「灵宝」）

> v0.1 · 2026-09-20 · Hermes Buddy 游戏推测/陪伴能力设计

## 一、灵宝方案拆解（公开资料调研）

王者荣耀「灵宝」（基于腾讯「绝悟」AI，2024 上线大厅聊天，2025-2026 迭代为局内外全场景伴侣）的公开能力与架构：

### 1. 核心链路（四段式）

```
事件感知（游戏内实时事件管道：击杀/死亡/助攻/装备/经济/防御塔）
  → LLM 决策（场景理解 + 决定说什么/不说什么 + 人设风格约束）
  → 语音合成 TTS（GVoice 实时语音）
  → 播报/对话（主动解说 + 玩家语音唤醒「灵宝灵宝」查战局/买装备/战术建议）
```

### 2. 关键产品经验（踩过的坑）

| 经验 | 说明 | 对 Hermes Buddy 的启示 |
|---|---|---|
| **知道什么时候不说** | MOBA 节奏快，解说太多是噪声；建议必须简短、择时、可打断 | 推测必须有节流 + 静默期，绝不在战斗高峰刷屏 |
| **「毒舌」人设争议** | 早期毒舌设定部分玩家反感 → 4 月版本加了三种互动风格 + 主动对话开关 | 风格必须可切换（唠嗑/战术/安静），主动说话必须可关 |
| **情绪感知** | 连败安慰、连胜庆祝 | 胜负结果类事件触发不同话术模板 |
| **操作代办 vs 建议的边界** | 灵宝可帮买装备/发信号，但战术建议克制——过多自动化变成干扰或不公 | Buddy 在游戏内**只说话不动手**，绝不注入键盘鼠标 |
| **个性化记忆** | 记住玩家常用英雄/习惯，给个性化提醒 | Buddy 已有偏好结晶（behavior-db），可复用 |

### 3. 与 Hermes Buddy 的本质差异

- 灵宝是**游戏内 SDK**：直接读游戏服务器事件流（击杀/经济），零 OCR 成本、100% 准确。
- Buddy 是**外部桌面伴侣**：拿不到游戏内部数据，只能靠**截屏 + 本地 VL** 推测画面。
- 推论：Buddy 的游戏模式不应追求「战术级」解说的准确性，而应主打**氛围陪伴 + 粗粒度状态播报**（在打游戏/在等加载/在打团/挂机摸鱼），这正是本地小 VL 能胜任的粒度。

## 二、Hermes Buddy 游戏陪伴模式设计

### 1. 场景识别（复用现有体系）

- 游戏进程识别：`scene-rules` 机制天然支持——内置 `scene-game` 规则，exeNames 覆盖
  常见游戏（`yuanshen`, `genshin`, `league of legends`, `league_client`, `crossfire`, `dnf`,
  `hive`, `mihoyo` 系，及王者荣耀 PC 版/模拟器进程），用户可在场景规则 UI 里自行加。
- 已验证：日志里 VL 已能识别「《原神》战斗场景，玩家在等待战斗结束」（06:30 的记录）。

### 2. 分档推测节奏（成本控制核心）

| 档位 | 截图频率 | 推测通道 | 输出 |
|---|---|---|---|
| 静默 | 不截图 | 无 | 只在桌宠显示「陪玩中」状态 |
| 陪伴（默认） | 每 3~5 分钟一帧 | 本地 VL（不花远端） | 桌宠气泡一句话（喵体），纯氛围 |
| 解说 | 每 60~90 秒一帧 | 本地 VL 判断事件显著度，显著才上远端 | 气泡 + 可选 TTS |

- 节流硬约束：游戏内**禁用一切键盘/剪贴板注入**（insertMode 强制无效化），
  只允许桌宠气泡说话——这是与灵宝对齐的「只陪伴不动手」边界。
- 本地 VL 先做「显著度过滤」：画面与上次比无显著变化（同一战斗场景）→ 不上远端、不说话。
  避免每分钟烧一次远端推理。

### 3. 话术风格（三种预设，对齐灵宝的 3 模式）

1. **唠嗑搭子**（默认）：口语化、短句、带点表情包语气。「这波打得不错喵！」「对面好像在偷龙？」
2. **战术参谋**：只在可确认的状态下说话（加载/结算/挂机），不做不可靠的战术判断。
3. **安静陪伴**：不主动说话，桌宠只做陪伴动画，用户点它才回应。

### 4. 交互入口

- 桌宠猫在游戏内变为「灵宝模式」气泡（现有 desktop-pet 气泡直接复用）。
- 语音唤醒/对话（灵宝的「灵宝灵宝」唤醒）：远期项，Electron 侧可接
  whisper.cpp 转写（语音转写链路已存在）+ 远端 LLM + 可选 TTS，但第一版不做。

### 5. 实施切分

- **P1（已有基础，约 1 个版本）**：scene-game 规则 + 游戏内禁注入 + 陪伴档（低频本地 VL + 气泡）。
- **P2**：显著度过滤 + 三风格话术 + 设置 UI（档位/频率/风格）。
- **P3**：语音唤醒 + TTS + 对局结算情绪化反馈（胜负安慰/庆祝模板）。
