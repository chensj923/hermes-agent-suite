# 具身智能系统 (Embodied Intelligence)

## 概述

Hermes Agent Suite 的具身智能模块将 AI Agent 从纯软件扩展到物理世界交互，通过三层反射架构实现对 IoT 设备的智能控制。

## 架构：三层反射

```
┌─────────────────────────────────────┐
│  L3: 大模型决策层                     │
│  - 复杂场景理解与规划                  │
│  - 自然语言指令解析                    │
│  - 多步骤任务编排                      │
├─────────────────────────────────────┤
│  L2: 语义映射层                       │
│  - 意图分类 (crystal_reflex)          │
│  - 设备能力匹配                        │
│  - 场景联动规则                        │
├─────────────────────────────────────┤
│  L1: 硬编码反射层                      │
│  - miIO 协议直连                       │
│  - MIoT Spec 设备规格                  │
│  - 低延迟开关控制                      │
└─────────────────────────────────────┘
```

## Crystal Reflex（结晶反射）

核心组件，位于 `/opt/hermes-suite/crystallization/crystal_reflex.py`。

### 功能
- **意图分类**：将用户自然语言指令映射到预定义动作
- **KV Cache 优化**：固定前缀预计算，推理速度 2x 提升
- **本地模型**：Qwen3-0.6B，支持 ModelScope/hf-mirror fallback

### API 端点
- `POST /` — 接收 prompt，返回分类结果和动作建议
- 服务端口：9124
- systemd 服务：`crystal-reflex.service`

### 模型加载优先级
1. 本地路径 `/opt/crystal-model/qwen3-06b-deploy`
2. ModelScope `Qwen/Qwen3-0.6B`
3. hf-mirror.com 镜像
4. HuggingFace（大陆可能不可达）

## IoT 设备接入

### 支持的协议
| 协议 | 特点 | 适用场景 |
|------|------|----------|
| miIO | 局域网直连，需 token | 小米设备快速控制 |
| MIoT Open API | 云端 OAuth2 | 跨品牌设备 |
| MIoT Spec | 公开设备规格查询 | 设备能力发现 |

### 已发现设备示例
- 扫地机器人 (192.168.0.165)
- 空气净化器 (192.168.0.163)
- 智能灯 (192.168.0.128)
- 温湿度传感器 (192.168.0.182)

## 结晶系统与具身智能的关系

结晶系统（Crystallization）为具身智能提供持续学习能力：

1. **形成期**：从用户交互中提取设备控制模式
2. **使用期**：playbook 规则加速常见操作
3. **回顾期**：统计准确率，淘汰失效规则

具身智能的控制经验会自动进入结晶循环，越用越智能。
