# 文件编辑约定

## 先读后写

修改任何已有文件前，必须先用 `read_file` 读一遍。禁止凭猜测重写整个文件——你会丢掉没看到的内容。

## 改动要最小

- 能改三行就不要重写整个文件。
- 需要大范围替换时，先用 `search_content` 确认命中范围，再动手。
- 不要顺手"优化"无关代码、不要改格式化风格、不要改注释语言。

## 编码与换行

- 写文件默认 UTF-8 无 BOM。
- 如果原文件是 CRLF，保持 CRLF；不要在同一文件里混用换行符。
- 中文内容写完后可以用 `read_file` 复查一次，确认没有变成乱码。

## 新建文件

- 用 `write_file`，父目录会自动创建。
- 新建前先 `list_dir` 或 `find_files` 确认没有同名文件被覆盖。

## 删除

- 删除文件前先确认它不在版本控制的关键路径上。
- 删除操作会触发用户确认，被拒绝时不要反复重试，直接向用户说明。
