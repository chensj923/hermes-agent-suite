服务端部署压缩包（随安装包自带）

      
把推理代理（8811）与 WS 通道（8822）两个外挂组件、执行脚本一起打成压缩包，随 Buddy 安装包发出。
        可手动拷到 Hermes 解开跑 deploy.sh，也可在 Windows 一键推送部署。

      

        
        
        
        
      

      
Hermes 跑在 Docker / 无 systemd 的 Linux 时，用这份独立脚本前台拉起 WS 通道（8822），无需 SSH 一键部署。详见部署包内 README「方式三」。
