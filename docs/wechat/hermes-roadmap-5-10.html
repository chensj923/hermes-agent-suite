在电脑上跟 AI 聊了半小时的方案，拿起手机再问一句，它礼貌地回你：

“请问你说的是哪件事？”

问题不在模型不够聪明。是三件事一直没被解决：

一、它不在你所有的设备上。

二、它记不住你。

三、它只会动嘴，不会动手。

Hermes Agent Suite 想解决的，就是这三件事。今天我们把接下来六个大版本的路线图完整公开。

先说清楚：Hermes 是什么

一套本地优先的 AI Agent 套件。大脑可以跑在你自己的服务器上，手脚长在你的电脑上，数据留在你自己手里——不把你的文件、屏幕、习惯交给别人的云。

目前（v4.8）已经落地的能力：

预测模式

本地小模型判断"该不该开口"，远端大模型负责思考。不该打扰的时候，它安静。

桌面伙伴

Live2D 角色常驻桌面，点一下就能让它看一眼屏幕、改文案、唤出主窗口。

三层记忆

即时记忆 / 本地向量索引 / 共享知识库，短期到长期都有地方放。

混合推理

本地、远端、本地+远端三档可选，模型文件也能自己指定，不强制下载。

路线图：5.0 → 10.0

5.0　全平台　规划中

补齐 Mac 客户端与移动端（iOS / Android）。从"一台电脑上的工具"，变成"你所有设备上的同一个人"。同一个账号、同一套智能体，走到哪用到哪。

6.0　记忆　规划中

本地与移动端的记忆双向同步；接入 IMA 与 AnythingLLM 作为外部记忆入口。

更重要的是重做记忆链路本身：什么值得记、记多久、什么时候该想起来、怎么想起来才算准。让"我记得你"不再是一句宣传语。

7.0　全端同步　规划中

智能体、工具、记忆、对话记录，在所有端保持一致。电脑上配好的智能体和工具，手机上打开就能接着用；昨晚在手机上聊到一半的话题，早上在电脑上能续上。

8.0　推理平台　规划中

模型调度优化，并在服务端搭建统一推理平台：多模型、多卡统一管理，按任务难度和成本自动选模型——简单问题小模型秒回，复杂问题交给大模型深思，不浪费一块算力。

9.0　具身：智能管家　规划中

接入物联网设备，从会聊天到会动手。灯、空调、净化器、扫地机——一句话的事。

但真正的目标不是语音开关，而是：它看得懂场景，知道你此刻需要什么，然后自己把事办了。

10.0　收口　规划中

把前面六步真正拧成一体：一个记得你、跟着你、能替你动手的助手。目标形态留到 9.0 落地后再定。

我们为什么把它公开
