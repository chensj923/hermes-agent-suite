⬇️ Windows (.exe) ⬇️ Linux (.AppImage) ⬇️ macOS (.dmg) 即将支持
安装说明：
Windows: 下载 .exe 安装包，双击运行，按提示完成安装。
Linux: chmod +x HermesBuddy.AppImage && ./HermesBuddy.AppImage
macOS: 打开 .dmg，拖入 Applications 文件夹。首次运行需在「系统设置 → 隐私与安全」中允许。

安装后打开 HermesBuddy，输入服务器地址 即可连接。
